# Product Overview

This is a **Gen AI Service** - a serverless AWS-based platform that orchestrates AI workflows through multiple processing pipelines.

## Core Capabilities

- **Web Scraping & Content Processing**: Automated content extraction and processing from web sources
- **Vector Database Operations**: FAISS-based vector storage and similarity search
- **AI Agent Framework**: Strands-based agents for weather, location, and general AI tasks
- **Real-time Communication**: WebSocket API for live client interactions
- **State Machine Orchestration**: Step Functions for complex workflow management
- **Multi-language Runtime Support**: JavaScript (LLRT), Python, and Rust Lambda functions

## Key Use Cases

- Content ingestion and vectorization for RAG applications
- AI-powered agent interactions with external APIs
- Real-time data processing and client notifications
- Scalable document processing and analysis workflows

The system is designed for high-throughput, event-driven AI workloads with emphasis on cost optimization through ARM64 architecture and LLRT runtime.
